# Realidade aumentada Xalingo

Central das experiências de realidade aumentada (RA) da Xalingo Brinquedos.
Publicado em https://inovacaoxalingo.github.io/ra/

Para incluir uma RA nova, edite a lista `RA` no fim do `index.html`
(status: "ok", "breve" ou "oculto"). O menu (inovacaoxalingo.github.io/menu)
lê essa mesma lista na busca dele.
